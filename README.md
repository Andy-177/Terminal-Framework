# Terminal-Framework

一个轻量级、可扩展的网页终端模拟器框架，提供多标签页支持，方便开发者在此基础上构建功能强大的网页终端应用。

## 版本说明

### Terminal.html（旧版 - 单标签）
极简的终端模拟器，适合快速体验或简单场景。

- ✅ 单标签页
- ✅ 键盘输入实时响应
- ✅ 回车换行、退格删除
- ✅ 闪烁光标效果
- ✅ 全屏黑色终端风格

### TerminalX（新版 - 多标签框架）
基于旧版全面升级，提供完整的终端框架支持，方便二次开发。

- ✅ **多标签页管理**：支持新建（Ctrl+T）、关闭（Ctrl+W）标签
- ✅ **智能标签伸缩**：标签栏溢出时自动缩窄非激活标签
- ✅ **独立终端内容**：每个标签拥有独立的输入缓冲区
- ✅ **横向滚动**：支持鼠标滚轮和触摸手势横向滚动标签栏
- ✅ **状态栏**：显示标签数量和实时时钟
- ✅ **平滑交互**：标签切换和滚动动画流畅
- ✅ **优雅暗色主题**：精致的深色 UI 设计

## 文件结构

```
Terminal-Framework/
├── Terminal.html    # 单标签版（基础版）
└── TerminalX.html   # 多标签框架版（推荐）
```

## 快速开始

1. 克隆仓库或直接下载 HTML 文件
2. 在浏览器中打开 `TerminalX.html` 或 `Terminal.html`
3. 点击终端区域即可开始输入

## 键盘快捷键（TerminalX）

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+T` | 新建标签页 |
| `Ctrl+W` | 关闭当前标签页 |
| `Enter` | 换行 |
| `Backspace` | 删除上一个字符 |

## 扩展开发

TerminalX 是一个灵活的终端框架，您可以在其基础上轻松添加：

- **命令解析系统**：识别 `ls`、`cd` 等命令并执行
- **历史记录**：使用 `↑`/`↓` 键浏览命令历史
- **自动补全**：Tab 键自动补全命令
- **主题切换**：支持亮色/暗色主题切换
- **文件系统模拟**：在内存中构建虚拟文件系统
- **远程连接**：通过 WebSocket 连接真实 Shell
- **自定义提示符**：修改终端提示符样式

## 技术栈

- **HTML5**：语义化结构

## 设计理念

- **模块化**：清晰的代码结构，便于理解和扩展
- **轻量级**：无第三方依赖，加载快速
- **可维护性**：核心功能与扩展功能分离
- **用户体验**：流畅的交互和精致的视觉效果
